# Expression Modules

Use these as interchangeable building blocks. Do not paste them mechanically. The goal is to keep structure stable while reducing repetitive phrasing.

## Core Rule
- Fixed structure is allowed.
- Mechanical wording is not.
- For chapter 2, do not start by listing A/B/C/D in order unless there is a specific reason.
- First identify the percentage pattern, then choose the matching opening and explanation style.

## Chapter 1: Introduction Modules

### Disease / Management Background Openings
- 高血压等慢性疾病管理强调长期达标、风险分层和持续随访，临床医生在处方决策中通常需要同时兼顾疗效控制与用药稳妥性。
- 在慢病诊疗场景中，医生对降压治疗的关注已不局限于短期指标改善，而更加重视长期控制、风险识别和患者管理的可执行性。
- 对高血压药物而言，临床应用价值不仅体现在治疗目标支持上，也体现在特殊人群管理、联合用药判断和随访便利性等多个维度。

### Product Relevance Openings
- 作为临床常见的复方降压制剂，{{品种}}在医生端的实际评价往往涉及达标效率、稳定控制、安全边界及处方便利性等多个层面。
- {{品种}}在临床使用中通常被放在长期管理和复方治疗框架下观察，因此医生反馈更容易反映真实处方场景中的判断重点。
- 对于{{品种}}这类单片复方制剂，医生关注点通常不仅包括药物本身表现，也包括依从性管理、联合用药适配和说明书指导性。

### Dimension Introduction Modules
- 本次调研围绕{{维度举例}}等{{维度总数}}个重点维度展开，重点观察医生在真实临床判断中的主要共识与关注点。
- 问卷内容覆盖{{维度举例}}等{{维度总数}}个核心维度，目的在于梳理医生对该品种在实际应用中的判断结构和管理侧重点。
- 调研重点涉及{{维度举例}}等{{维度总数}}项内容，希望从医生端视角还原该品种在处方、监测和患者管理中的实际反馈。

### Purpose Closing Modules
- 报告旨在基于受访医生反馈，对该品种的临床应用特点、管理难点和后续优化方向进行系统整理。
- 本报告希望在不超出问卷数据边界的前提下，为后续合理用药沟通、风险提示和支持材料优化提供参考。
- 通过对医生反馈的结构化分析，报告拟为后续场景化管理、学术支持和用药信息完善提供依据。

## Chapter 1.1: Background Modules

### Clinical Background Openings
- 在实际诊疗过程中，医生往往需要同时处理血压控制目标、特殊人群适配性、合并症管理以及长期依从性维护等多重问题。
- 从临床管理角度看，复方降压方案的评价通常建立在疗效、安全性、信息支持和执行便利性等多个因素的综合权衡之上。
- 对医生而言，药物管理不仅是处方动作本身，还包括处方前评估、风险识别、患者教育和随访监测等连续环节。

### Doctor Attention Focus Modules
- 因此，医生在相关问卷中的反馈，往往更能体现真实临床场景下的关注重点，而不仅是对产品印象的简单判断。
- 这类调研的价值，在于把医生在日常处方、复诊和管理中的隐性判断显性化，便于识别稳定共识与局部差异。
- 相较于单纯的满意度表达，医生端问卷更能反映处方逻辑、风险边界和执行层面的实际需求。

### Management Value Modules
- 通过梳理这些反馈，可以更有针对性地识别哪些环节已具备较好认知基础，哪些环节仍需要细化指导或补充支持。
- 这类信息有助于后续在医生端支持材料、监测提示和场景化沟通中提高针对性和一致性。
- 对同类报告而言，这部分背景的意义在于为后续章节中的数据解读建立稳定的临床语境，而不是单纯重复引言内容。

## Chapter 2: Opening Modules

### Consensus-Dominant
Use when the top two options clearly dominate and represent the main doctor judgement.

- 调研结果显示，受访医生对该维度的整体反馈较为积极，主流判断集中在……
- 从选项分布看，临床医生对该问题已形成相对明确的共识，主要倾向于……
- 就该维度而言，医生端反馈整体偏向认可，其中更集中的判断体现在……
- 从本题结果看，医生对该项表现的评价总体较稳定，主要意见集中在……

### Cautious-Recognition
Use when feedback is generally positive but clearly framed by monitoring, evaluation, or conditional use.

- 整体来看，医生对该维度持相对认可态度，但这种认可更多建立在规范评估和持续监测基础上。
- 调研结果反映出，临床医生对该项表现总体接受度较高，但同时保留了较强的风险识别意识。
- 从反馈分布看，多数医生认可该维度的临床应用价值，但并未脱离个体化判断前提。
- 受访医生整体倾向于正向评价该项表现，不过在特殊场景下仍强调审慎处理。

### Split-Judgement
Use when several options are close and doctor judgement is not strongly concentrated.

- 从本题占比结构看，医生判断并未明显集中于单一方向，显示出一定程度的临床分歧。
- 调研结果提示，受访医生对该维度的理解和处理策略存在差异，尚未形成高度统一的判断。
- 就该问题而言，不同选项之间占比较为接近，反映出医生在实际处方场景中的考虑重点并不完全一致。
- 本题反馈呈现出一定分层特征，说明临床医生在该维度上的决策更依赖具体场景而非单一标准。

### Risk-Attention
Use when negative or conservative options are not low and the discussion should foreground concerns.

- 本题结果提示，除主流判断外，医生对该维度仍保留较明显的风险顾虑。
- 从反馈分布看，该问题并非单纯的正向认可结构，部分医生的关注点更多集中在……
- 调研结果反映出，医生在评价该维度时，除认可因素外，仍明显关注潜在风险和管理难点。
- 就临床应用而言，该维度的反馈不仅体现认可，也提示特定场景下仍存在需要重点识别的问题。

## Chapter 2: Clinical Interpretation Modules

### Efficacy / Control
- 这类反馈通常反映出医生更关注实际达标效率及长期管理中的稳定控制表现。
- 该结果在一定程度上体现了临床医生对治疗目标落实情况的直观判断。
- 从医学管理逻辑看，医生更看重的并不只是短期反应，而是持续控制和随访中的可管理性。

### Safety / Special Populations
- 这一反馈说明医生在评价该维度时，除疗效外，同样重视特殊人群中的耐受性与监测边界。
- 相关判断与老年患者、肝肾功能状态、合并基础疾病等因素密切相关。
- 对特殊人群而言，临床决策往往不是简单“能不能用”，而是“在什么前提下更稳妥地用”。

### Combination Therapy
- 这类结果通常反映医生对机制互补、风险叠加及监测要求的综合权衡。
- 在联合治疗场景中，医生关注的不仅是效果提升空间，也包括相互作用和管理复杂度。
- 从临床实践看，联合用药评价往往建立在处方灵活性与风险控制并重的基础上。

### Adherence / Management
- 该反馈更多体现医生对长期用药执行力和患者管理难点的观察。
- 在慢病管理场景下，依从性往往直接影响方案的实际落地效果。
- 这类结果说明医生关注的不只是药物本身，也包括患者是否能够持续、规范地执行治疗方案。

### Label / Support
- 这一分布反映出医生对信息可得性和决策支持效率的实际感受。
- 对处方场景而言，说明书和支持材料的价值在于帮助医生快速识别边界、降低判断成本。
- 相关反馈提示，该维度不仅影响认知，也影响临床执行过程中的便利性和稳妥性。

## Chapter 2: Closing Reminder Modules

- 临床应用中，仍建议结合患者基础情况和具体处方场景进行审慎判断。
- 在实际管理中，可进一步结合随访、监测和患者教育提升该维度的执行效果。
- 对于特殊人群或复杂并用药场景，仍需在常规判断基础上加强风险识别。
- 后续处方与随访过程中，建议围绕该维度保持持续关注和动态评估。
- 该结果提示，在医生端管理中仍需兼顾主流应用价值与少数场景下的风险提示。

## Prompt Reinforcement
When converting these modules into prompt instructions, explicitly require:
- start from judgement, not from enumeration
- embed percentages naturally
- vary opening sentences across adjacent items
- choose expressions according to data pattern
- avoid repeated paragraph skeletons across all questions
- for introduction/background, vary the disease-background opening, product relevance sentence, and purpose closing instead of reusing one stock paragraph every time
