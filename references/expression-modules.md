# Expression Modules

Use these as interchangeable building blocks. Do not paste them mechanically. The goal is to keep structure stable while reducing repetitive phrasing.

## Core Rule
- Fixed structure is allowed.
- Mechanical wording is not.
- For chapter 2, do not start by listing A/B/C/D in order unless there is a specific reason.
- First identify the percentage pattern, then choose the matching opening and explanation style.

## Anti-Pattern Rotation Rule
When multiple items share the same pattern type (e.g. 8 consensus-dominant items), you MUST use different opening modules for adjacent items. Never repeat the same opening module within 4 consecutive items. If you reach the end of the module list, you may cycle back but change the internal structure (e.g. start with data first on one item, start with judgement first on the next).

### Consensus-Dominant（共识集中型）
Use when the top two options clearly dominate and represent the main doctor judgement.

1. 调研结果显示，受访医生对该维度的整体反馈较为积极，主流判断集中在……
2. 从选项分布看，临床医生对该问题已形成相对明确的共识，主要倾向于……
3. 就该维度而言，医生端反馈整体偏向认可，其中更集中的判断体现在……
4. 从本题结果看，医生对该项表现的评价总体较稳定，主要意见集中在……
5. 受访医生在本维度上的反馈集中度较高，多数医生的判断方向保持一致，主要体现在……
6. 根据调研数据，该维度在医生群体中形成了较强的判断一致性，反馈集中在……
7. 问卷数据表明，医生对该问题的态度整体趋同，认可方向主要集中在……
8. 从医生端的反馈结构看，该维度的评价呈现明显的收敛趋势，核心判断指向……
9. 综合分析显示，受访医生在这一维度上的立场较为一致，多数医生倾向于认为……
10. 就反馈分布而言，该问题的医生评价高度集中，核心关切和认可均围绕……

### Cautious-Recognition（审慎认可型）
Use when feedback is generally positive but clearly framed by monitoring, evaluation, or conditional use.

1. 整体来看，医生对该维度持相对认可态度，但这种认可更多建立在规范评估和持续监测基础上。
2. 调研结果反映出，临床医生对该项表现总体接受度较高，但同时保留了较强的风险识别意识。
3. 从反馈分布看，多数医生认可该维度的临床应用价值，但并未脱离个体化判断前提。
4. 受访医生整体倾向于正向评价该项表现，不过在特殊场景下仍强调审慎处理。
5. 调研数据显示医生对该维度总体持正面态度，但这种正面判断带有明显的条件性，主要体现在……
6. 从评价结构看，医生认可的同时也保留了较为清晰的风险边界意识，尤其在……
7. 医生端反馈虽以认可为主，但分析其深层逻辑，可发现这种认可建立在明确的临床前提之上。
8. 本维度反映出一种"有条件认可"的医生态度格局，核心认可与情境性保留并存。

### Split-Judgement（分歧分散型）
Use when several options are close and doctor judgement is not strongly concentrated.

1. 从本题占比结构看，医生判断并未明显集中于单一方向，显示出一定程度的临床分歧。
2. 调研结果提示，受访医生对该维度的理解和处理策略存在差异，尚未形成高度统一的判断。
3. 就该问题而言，不同选项之间占比较为接近，反映出医生在实际处方场景中的考虑重点并不完全一致。
4. 本题反馈呈现出一定分层特征，说明临床医生在该维度上的决策更依赖具体场景而非单一标准。
5. 各选项之间分布较为分散，未见某一方向占据绝对主导，提示医生群体在该维度上的判断逻辑存在多元性。
6. 从占比结构观察，该问题呈现出多中心分布的特征，医生的判断立场分布在多个可能的路径上。
7. 问卷结果显示，医生对该问题的回答未形成单一主流，不同临床考量路径均有相当比例的医生选择。
8. 本题的反馈分布呈较为均衡的多极格局，反映出当前临床实践中医生在该维度上尚无统一的处理范式。

### Risk-Attention（风险关注型）
Use when negative or conservative options are not low and the discussion should foreground concerns.

1. 本题结果提示，除主流判断外，医生对该维度仍保留较明显的风险顾虑。
2. 从反馈分布看，该问题并非单纯的正向认可结构，部分医生的关注点更多集中在……
3. 调研结果反映出，医生在评价该维度时，除认可因素外，仍明显关注潜在风险和管理难点。
4. 就临床应用而言，该维度的反馈不仅体现认可，也提示特定场景下仍存在需要重点识别的问题。
5. 从数据分布看，即便在整体认可的基础上，仍有相当比例的医生对本维度持审慎或保留态度，风险信号不容忽视。
6. 该维度呈现出一种"认可中有顾虑"的结构特征，医生的正向判断与风险关注并存且均不可忽略。
7. 调研反馈提示，该问题所涉及的潜在风险或管理难点，在当前的医生判断体系中占有较为突出的权重。
8. 除正向反馈外，本题中持保守态度的医生比例值得关注，反映出该维度在临床管理中的边界条件仍需进一步厘清。

## Chapter 2: Clinical Interpretation Modules

### Efficacy / Control（疗效与控制）

1. 这类反馈通常反映出医生更关注实际达标效率及长期管理中的稳定控制表现。
2. 该结果在一定程度上体现了临床医生对治疗目标落实情况的直观判断。
3. 从医学管理逻辑看，医生更看重的并不只是短期反应，而是持续控制和随访中的可管理性。
4. 这种判断分布反映出医生在血压控制方面的评价更偏向实用主义，关注的是患者在真实诊疗轨迹中的反应模式。
5. 该维度的反馈结构提示，临床医生对达标路径的认知并非单一维度，而是涵盖了快速起效与长期维持的复合期待。

### Safety / Special Populations（安全性与特殊人群）

1. 这一反馈说明医生在评价该维度时，除疗效外，同样重视特殊人群中的耐受性与监测边界。
2. 相关判断与老年患者、肝肾功能状态、合并基础疾病等因素密切相关。
3. 对特殊人群而言，临床决策往往不是简单"能不能用"，而是"在什么前提下更稳妥地用"。
4. 医生对安全性的关注呈现出一种"分层管理"的思维模式：低风险人群常规使用，高风险人群审慎评估。
5. 该类反馈的深层逻辑在于，医生更看重安全性信息的可操作性和边界清晰度，而不仅是安全性声明的存在本身。

### Combination Therapy（联合用药）

1. 这类结果通常反映医生对机制互补、风险叠加及监测要求的综合权衡。
2. 在联合治疗场景中，医生关注的不仅是效果提升空间，也包括相互作用和管理复杂度。
3. 从临床实践看，联合用药评价往往建立在处方灵活性与风险控制并重的基础上。
4. 医生对联合方案的态度实质上是对"增效空间"与"安全保障"两个变量的同时考量。
5. 该维度的反馈结构提示，临床医生在联合用药决策中更多依赖机制合理性和个体化评估，而非统一标准。

### Adherence / Management（依从性与管理）

1. 该反馈更多体现医生对长期用药执行力和患者管理难点的观察。
2. 在慢病管理场景下，依从性往往直接影响方案的实际落地效果。
3. 这类结果说明医生关注的不只是药物本身，也包括患者是否能够持续、规范地执行治疗方案。
4. 依从性评价的本质是医生对"方案在真实世界中的执行力"的判断，而非仅对药物属性的评价。
5. 医生对依从性的观察往往融合了患者社会经济因素、教育沟通效果和药物可接受度等多层面信息。

### Label / Support（信息支持）

1. 这一分布反映出医生对信息可得性和决策支持效率的实际感受。
2. 对处方场景而言，说明书和支持材料的价值在于帮助医生快速识别边界、降低判断成本。
3. 相关反馈提示，该维度不仅影响认知，也影响临床执行过程中的便利性和稳妥性。
4. 医生对信息支持的评价实际上是对"在有限时间内做出稳妥决策所需的辅助工具质量"的综合体验。
5. 说明书和支持材料的完善程度直接关系到医生日常工作的效率和处方信心，因此该维度的反馈具有较强的实践指向性。

## Prompt Reinforcement
When converting these modules into prompt instructions, explicitly require:
- Start from judgement, not from enumeration
- Embed percentages naturally
- Vary opening sentences across adjacent items — do NOT repeat the same module within 4 consecutive paragraphs
- Choose expressions according to data pattern
- Avoid repeated paragraph skeletons across all questions
- For introduction/background, vary the disease-background opening, product relevance sentence, and purpose closing instead of reusing one stock paragraph every time
- In batch scenarios (multiple reports with different product/region), vary the module rotation starting point for each report to reduce inter-report similarity
- When cycling back through modules due to high item count, change the internal paragraph structure (e.g. judgement→data vs data→judgement) to avoid perceptible repetition
